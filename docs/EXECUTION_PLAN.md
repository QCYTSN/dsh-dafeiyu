# DSH 大肥鱼插件 MVP 执行计划

## 最终目标

用户只在 DSH 中启用大肥鱼。启用后，大肥鱼以透明置顶窗口存在于 Windows 或 Linux 桌面，
持续反映 DSH 顶层任务状态；切换到其他应用不会消失，DSH Host 退出后不留下独立进程。

## MVP 必须满足

- DSH 是唯一启用、禁用和配置入口。
- Helper 是 DSH 子进程，不提供独立启动器、登录、聊天或更新中心。
- 支持空闲、思考、工具工作、等待用户、完成、失败六类状态。
- 状态动画持续到真实状态变化；短互动结束后恢复最新 DSH 状态，而非固定回到空闲。
- 多个顶层 Session 并发时自动选择最值得提醒的一个；子 Agent 默认不抢占宠物。
- 保留大肥鱼的微动作、Agent 动作和轻互动，但删除与 DSH 无关的养成和系统监控。
- 不截图、不读其他窗口正文、不保存模型 Key、不启动网络监听、不发送遥测。
- Windows / Linux 安装后不要求用户单独安装 Python。

## 状态优先级

从高到低：

1. `WAITING`：等待输入或审批。
2. `ERROR`：阻塞或失败。
3. `SUCCESS`：任务完成、尚处于提示脉冲。
4. `WORKING`：工具正在运行。
5. `THINKING`：模型正在处理。
6. `IDLE`：无活动任务。

同优先级按最近事件时间选择；未来的手动固定 Session 高于自动选择。

## 动作迁移白名单

- 核心状态：`idle_front`、`idle_think`、`sweep`、`talk`、`happy`、`angry`、`dizzy`。
- 微动作：`idle_blink`、`idle_glance`。
- 行走：`walk_side`、`walk_side_right` 及左右起步/收步。
- 轻互动：`head_pat`、`poke_react`、`tail_react`。
- 桌面操作：`dragging`。

首版不迁移喂食、睡眠养成、抛掷/坠落、窗口顶部落脚和完整本地语料。

## 阶段与完成门槛

### 1. 产品契约

- 本文、产品取舍文档和协议状态一致。
- 所有后续功能能归入 MVP 必须项，否则延后。

### 2. 资产与授权

- 只复制白名单中的 238px 运行时帧，不复制候选图、付费参考图或源素材。
- 插件包明确区分 MIT 代码和非 MIT 角色视觉资产。
- 生成可校验的插件动作清单，缺帧时可回退而不是崩溃。

### 3. 动画内核

- 主状态循环、一次性脉冲、微动作层、互动覆盖与恢复均有测试。
- 中文气泡、缩放和高 DPI 下不裁切。
- 减少动态模式不会播放走动或高频微动作。

### 4. DSH 状态聚合

- 并发顶层 Session 按优先级自动选择。
- 等待、失败和完成不会被低优先级新事件错误覆盖。
- Helper 重启后能收到完整状态快照；未知 DSH 事件安全忽略。

### 5. 桌面交互

- 支持拖动、摸头/戳/尾巴、右键本次隐藏和关闭。
- 位置、尺寸和减少动态持久化；多显示器变化后位置可恢复到可见区域。
- 互动结束恢复最新 Agent 状态。

### 6. DSH 设置入口

- DSH 中提供启用、尺寸、活动强度、减少动态和开机随 Host 出现。
- 设置写入 DSH 插件配置，不建立第二套完整设置应用。
- 禁用后立即退出 Helper；重新启用能恢复。

### 7. Windows / Linux 分发

- Helper 构建为无 Python 依赖的 Windows 与 Linux x64 产物。
- npm 插件包或发布包包含正确平台文件、许可证和校验信息。
- 升级、回滚和缺失 Helper 均给出可理解错误，不残留孤儿进程。

### 8. 最终验收

- 真实 DSH：空闲 → 思考 → 工具 → 等待/完成/失败状态正确。
- DSH 最小化和切换应用时宠物仍置顶；DSH 退出后宠物消失。
- 连续运行、Helper 崩溃、DSH 异常退出、多 Session 和多显示器场景通过。
- CPU、内存、启动时间和安装体积形成基线报告。
