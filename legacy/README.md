# Archived character assets / 旧角色素材归档

This directory preserves earlier character artwork and community dragging
frames. It contains source material only: no runnable plugin, no release
archive, and no current animation manifest. It is excluded from the npm package.
The original licensing terms are recorded in [ASSET_LICENSE.md](../ASSET_LICENSE.md).

此目录只保留旧角色素材，不是另一个插件版本，也不是安装入口。当前角色使用
`assets/pet/`；安装请前往[最新版发布页](https://github.com/QCYTSN/dsh-dafeiyu/releases/latest)，
选择 `dsh-dafeiyu-<版本号>.tgz`，或按主 README 在 DSH 中安装。
